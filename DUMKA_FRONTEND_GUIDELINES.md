# DUMKA Frontend Guidelines

Цей файл фіксує стильову систему для преміального ecommerce-рівня DUMKA. Його варто читати перед змінами в UI, щоб сайт не скочувався у мас-маркетну візуальну мову.

Джерела актуального бренд-контексту: старий сайт `https://nadiyadumka.com/` і Shopify-вітрина `https://j06wf9-vp.myshopify.com/`. На 2026-04-18 актуальний сезонний фокус із Shopify: колекція `Маки` весна-літо 2026. `GRONO` осінь-зима 2025/26 лишається важливою архівною та медійною згадкою.

## 1. Позиціонування

DUMKA продає не просто одяг, а статус, естетику, подію та сервіс. Інтерфейс має відчуватися як сторінка з глянцевого editorial-видання: спокійний, просторий, точний, без візуального шуму.

Ключові принципи:

- Quiet luxury: багато повітря, мало декоративних ефектів.
- Візуал важливіший за текст: фото мають займати основну площу екрана.
- Повільні, стримані мікроінтеракції: fade-in, hover scale до `1.03`, м'які drawer-переходи.
- Жодних яскравих кольорових плашок. Акценти створюють самі фото колекцій.

## 2. Кольори

Базова палітра:

- Основний фон сторінок: чистий білий `#FFFFFF`.
- Основний текст: `#111111`.
- Додатковий текст: `rgba(17, 17, 17, 0.55-0.70)`.
- Темні editorial-секції: `#111111` з білим текстом.

Не використовувати:

- Насичені промо-кольори.
- Градієнтні фони як головний прийом.
- Великі кольорові бейджі, stickers, sale-плашки без окремої дизайн-причини.

## 3. Типографіка

Поточна пара:

- Headings: `Cormorant Garamond`.
- Body / UI: `Inter`.

Правила:

- Заголовки мають бути великими, легкими за вагою, з editorial-настроєм.
- UI-текст і навігація можуть бути uppercase, але мають лишатися стриманими.
- Не стискати текст у щільні блоки. Краще коротші абзаци та більше інтервалів.

## 4. Компоненти

### Header

- Sticky / fixed.
- На hero поверх фото, після скролу переходить у світлий монохромний фон.
- Зліва: меню та пошук.
- Центр: логотип.
- Справа: мова та кошик.
- Розширена навігація відкривається через drawer.

### Buttons

- Primary: чорна кнопка з білим текстом.
- Secondary: прозора кнопка з тонкою рамкою.
- Text link: підкреслення або тонка hover-лінія.
- Радіус мінімальний: `0-2px`, максимум `8px`.

### Inputs

- Мінімалістичні поля без коробки.
- Тільки нижня лінія.
- Floating label при фокусі або заповненому значенні.

### Drawers

- Меню, пошук і кошик відкриваються збоку.
- Додавання товару не має перекидати користувача на сторінку кошика.
- Після `Add to cart` показувати cart drawer з товаром і CTA до checkout.

## 5. Home Page Structure

Обов'язковий каркас:

1. Hero на весь екран з editorial-фото або відео. Для актуального сезону використовувати `Маки`, `Весна / Літо 2026`.
2. Statement block з короткою філософією бренду.
3. Curated edit / products.
4. Асиметричні категорії: сукні, костюми, вечірній одяг.
5. Lookbook / campaign із концепцією сезону.
6. Showroom: вул. Шпитальна, 1, Львів, ТЦ "Магнус", 3-й поверх, запис на примірку.
7. Footer: підписка, сервісні сторінки, соцмережі.

## 6. Product Listing Page

Якщо додається PLP:

- Не робити важкий sidebar.
- Фільтри відкривати через горизонтальне меню або drawer.
- На desktop показувати 2-3 товари в ряд.
- Картка товару: велике фото, назва, ціна, hover-зміна фото або легкий scale.
- Категорії з Shopify: сукні, костюми, блузи, вечірній одяг, жилети, топи, шорти, комбінезони, аксесуари, подарунки.
- У новій колекції Shopify показує 43 товари. Орієнтир назв для seasonal copy: `Petalia Veil`, `Atrum`, `Umbra Lumen`, `Poppy Veil Elegance`, `Velour Poetry`, `Petal Grace`, `Weal Power`, `Axis Power`, `Pavera Rubin`.

## 7. Product Detail Page

PDP має працювати як преміальна вітрина:

- Великі вертикальні фото, які користувач скролить.
- Sticky purchase block справа на desktop.
- Розміри як клікабельні chips, не select.
- Опис, тканина, догляд, доставка через accordions.
- Після додавання товару відкривається cart drawer.
- Обов'язково тримати блок `Complete the look` для стилізації та cross-sell.

## 8. Copywriting

Писати як бренд, а не як шаблон:

- Менше пояснень, більше відчуття.
- Не описувати інтерфейс словами на кшталт “тут ви можете”.
- Уникати дешевих промо-фраз: “найкраща пропозиція”, “купуйте зараз”, “топ продажів”.
- Краще: “Примірка у флагманському просторі”, “Дивитися образи”, “Відкрити колекцію”.

## 9. Технічні орієнтири

- Next.js + React + Tailwind v4.
- Компоненти тримати маленькими й осмисленими.
- Візуальні стани реалізовувати через CSS transitions або легкий client state.
- Не додавати важкі бібліотеки без потреби.
- Перед здачею запускати `npm run build`.
